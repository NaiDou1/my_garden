# 按钮 Button
---
## 一、方块状态

按钮有 3 个方块状态：

| 属性      | 类型                | 含义                                                                         | 默认值            |
| --------- | ------------------- | ---------------------------------------------------------------------------- | ----------------- |
| `FACE`    | `AttachFace`        | 按钮附着在方块的哪个面：`FLOOR`（地面）、`CEILING`（天花板）、`WALL`（侧面） | `AttachFace.WALL` |
| `FACING`  | `Direction`（水平） | 按钮的朝向，与 `FACE` 共同决定按钮的按压方向                                 | `Direction.NORTH` |
| `POWERED` | `BooleanProperty`   | 按钮是否被按下、输出红石信号                                                 | `false`           |

- `FACE` 与 `FACING` 组合通过 `getConnectedDirection(state)` 计算出按钮的输出方向
- 放置时，根据玩家点击的面和视角方向自动确定 `FACE` 和 `FACING`。
---

## 二、计划刻的添加条件

按钮**只在被按下时**添加计划刻，用于在延迟后自动恢复。

- 按下按钮时，会添加一个延迟为 `ticksToStayPressed` 的计划刻。
- `ticksToStayPressed` 由构造参数传入：
  - 木质按钮：通常为 30 gt；
  - 石质按钮：通常为 20 gt。
- 计划刻的优先级为默认的 `0`。
- 如果按钮在计划刻执行的时候被再次触发（例如箭持续压住），会重新添加计划刻，刷新按压时间。
  详情见下方

## 三、按钮按下

按钮的按压分三种触发方式：玩家交互、(风弹)爆炸触发、箭激活。

### 1. 玩家交互

- 如果按钮**已经处于按下状态**，直接返回
- 如果按钮**未按下**，调用 `press` 方法。

`press` 方法执行步骤如下：

1. **设置按下状态**：  
   将 `POWERED` 设为 `true`，产生状态更新（PP）。
2. **发出邻居更新(NC)**：  
   `updateNeighbours(state, level, pos);`  
3. **添加计划刻事件**：  
   `level.scheduleTick(pos, this, this.ticksToStayPressed);`  
4. **播放声音**：  
   `playSound(player, level, pos, true);`  
5. **发送游戏事件**：  
   `level.gameEvent(player, GameEvent.BLOCK_ACTIVATE, pos);`

### 2. （风弹）爆炸触发

- 如果爆炸可以触发方块（`explosion.canTriggerBlocks()`）且按钮当前**未按下**，调用 `press` 方法按下按钮。
- 如果风弹的来源是旋风人，还会检查**生物破坏**`mobGriefing`是否为True
- 如果按钮已经按下，则不会重复触发。

### 3. 箭激活（仅适用于支持箭激活的按钮）

只有 `type.canButtonBeActivatedByArrows()` 返回 `true` 的按钮（木质按钮）才会响应箭。

- **实体进入**：`entityInside` 检测到实体进入按钮空间时，如果按钮未按下且支持箭激活，调用 `checkPressed` 方法。



## 四、计划刻执行时
如果按钮处于按下状态，调用 `checkPressed` 重新检查是否仍需保持按下。
`checkPressed` **方法逻辑**：

1. 查找按钮碰撞箱内是否有箭
2. 根据箭的存在与否判断按钮当前应该是什么状态：
   - `shouldBePressed = (firstArrow != null)`。
3. 如果目标状态与当前状态不同：
   - 更新方块状态为第二步计算的状态（发出状态更新）；
   - 发出邻居更新(NC)
   - 播放对应声音（按下或释放）；
   - 发送对应游戏事件（`BLOCK_ACTIVATE` 或 `BLOCK_DEACTIVATE`）。
4. 如果目标状态为按下（箭存在），重新添加计划刻 `ticksToStayPressed`，刷新按压时间。
