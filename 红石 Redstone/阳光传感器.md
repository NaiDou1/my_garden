# 阳光传感器 Daylight Detector

---
## 一、阳光传感器的方块状态

阳光传感器有 2 个方块状态：

| 属性                    | 类型              | 含义                         | 默认值  |
| ----------------------- | ----------------- | ---------------------------- | ------- |
| `POWER` / `power`       | `IntegerProperty` | 输出的红石信号强度（0 ~ 15） | `0`     |
| `INVERTED` / `inverted` | `BooleanProperty` | 是否处于反转（夜间）模式     | `false` |

- 默认注册状态为 `POWER=0, INVERTED=false`。
- 该方块没有覆盖 `getStateForPlacement`，放置时不会根据当前天空亮度立即调整，而是先使用默认状态。
- 方块形状为 `Block.column(16.0, 0.0, 6.0)`，高度为 6 像素；`useShapeForLightOcclusion` 返回 `true`，形状参与光照遮挡计算。

## 二、周期更新的触发条件
阳光传感器依赖方块实体 `DaylightDetectorBlockEntity` 的 ticker 进行周期检查。

方块实体类型为 `BlockEntityTypes.DAYLIGHT_DETECTOR`，本身不保存额外数据，仅用于驱动周期 ticker。

仅当以下条件同时满足时，会注册 ticker：

- 当前在服务端（`!level.isClientSide()`）；
- 当前维度类型启用天空光照（`level.dimensionType().hasSkyLight()`）。

输出信号强度每 20 个游戏刻（1 秒）检查并更新一次；如果当前游戏时间不是 20 的倍数，则不执行更新。

## 三、执行周期更新时的逻辑

每次调用 `updateSignalStrength` 时：

1. 获取当前有效天空亮度：

   ```java
   int target = level.getEffectiveSkyBrightness(pos);
   ```

2. 获取太阳角度并转换为弧度：

   ```java
   float sunAngle = level.environmentAttributes()
       .getValue(EnvironmentAttributes.SUN_ANGLE, pos)
       * (float) (Math.PI / 180.0);
   ```

3. 根据 `INVERTED` 模式计算目标输出：

   - 反转模式（`INVERTED == true`）：

     ```java
     target = 15 - target;
     ```

     不进行余弦调制。

   - 普通模式（`INVERTED == false`）且 `target > 0`：

     ```java
     float offset = sunAngle < Math.PI ? 0.0F : (float) (Math.PI * 2);
     sunAngle += (offset - sunAngle) * 0.2F;
     target = Math.round(target * Mth.cos(sunAngle));
     ```

     输出会被太阳角度余弦值调制。

   - 普通模式下如果 `target == 0`，保持为 `0`。

4. 将目标值限制在合法范围：

   ```java
   target = Mth.clamp(target, 0, 15);
   ```

5. 如果当前 `POWER` 与目标值不同：

   ```java
   level.setBlockAndUpdate(pos, state.setValue(POWER, target));
   ```

   如果相同，则不更新方块状态。

## 四、阳光传感器的响应流程

- **放置后**：
  - 先以默认状态 `POWER=0, INVERTED=false` 存在。
  - 等 ticker 运行到 `gameTime % 20 == 0` 时，会执行一次信号强度更新。

- **玩家右键切换模式**：
  - 仅当玩家有建造权限（`player.mayBuild()`）时才处理。
  - 只在服务端执行。
  - 翻转 `INVERTED` 状态：

    ```java
    BlockState newState = state.cycle(INVERTED);
    ```

  - 使用 `level.setBlock(pos, newState, 2)` 更新方块状态。
  - 触发 `GameEvent.BLOCK_CHANGE` 方块变化事件。
  - 立即调用 `updateSignalStrength(newState, level, pos)`，不等下一个 20 gt 周期。

- **作为红石信号源**：
  - `isSignalSource` 返回 `true`。
  - `ownSignal` 返回当前 `POWER` 值，因此相邻红石线等可以读取到输出强度。

- **普通模式 / 反转模式**：
  - 普通模式：天空亮度经太阳角度余弦调制后输出，天空越亮输出越强。
  - 反转模式：输出为 `15 - 天空亮度`，天空越暗输出越强。    i
