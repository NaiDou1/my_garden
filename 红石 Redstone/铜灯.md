# 铜灯 Copper Bulb
---

## 一、方块状态

铜灯有 2 个方块状态：

| 属性      | 类型              | 含义                 | 默认值  |
| --------- | ----------------- | -------------------- | ------- |
| `LIT`     | `BooleanProperty` | 铜灯是否点亮         | `false` |
| `POWERED` | `BooleanProperty` | 铜灯是否收到红石信号 | `false` |

- `LIT` 只会在红石信号从无到有时翻转。
- `POWERED` 表示当前是否有相邻红石信号输入，与 `LIT` 相互独立。
- 默认状态为 `LIT=false, POWERED=false`。

---

## 二、状态检查的触发条件
状态检查只在以下两个服务端时机调用 `checkAndFlip`：

1. **放置/替换时**：`onPlace`  
   - 仅当旧方块不是铜灯时执行。  
   - 因此新放置的铜灯如果周围已有红石信号，会立即检查并可能切换一次亮灭。

2. **邻居变化时**：`neighborChanged`  
   - 相邻方块、红石组件或红石信号发生变化时执行。

- 只在 `ServerLevel` 执行。  
- 不添加任何计划刻事件。

---

## 三、红石信号检查与翻转逻辑

`checkAndFlip` 方法逻辑如下：

1. 获取当前位置的红石输入信号：

   ```java
   boolean signal = level.hasNeighborSignal(pos);
   ```

2. 如果 `signal == state.getValue(POWERED)`，不做任何处理。

3. 如果 `signal != state.getValue(POWERED)`：

   - **无信号 → 有信号（上升沿）**  
     当前 `POWERED == false`，且 `signal == true`：
     1. 翻转 `LIT`：  
        `newState = newState.cycle(LIT);`
     2. 播放声音：
        - 翻转后 `LIT == true` → `SoundEvents.COPPER_BULB_TURN_ON`
        - 翻转后 `LIT == false` → `SoundEvents.COPPER_BULB_TURN_OFF`
     3. 设置 `POWERED = true` 并更新方块状态。

   - **有信号 → 无信号（下降沿）**  
     当前 `POWERED == true`，且 `signal == false`：
     1. 不翻转 `LIT`，不播放声音。
     2. 设置 `POWERED = false` 并更新方块状态。

> 铜灯只在红石信号出现时切换一次亮灭；信号消失时只清除 `POWERED`，`LIT` 保持。

---

## 四、红石输出

- `hasAnalogOutputSignal` 始终返回 `true`，因此铜灯可以被比较器检测。
- `getAnalogOutputSignal` 输出：
  - `LIT == true` → 输出强度 `15`
  - `LIT == false` → 输出强度 `0`

- 比较器输出只由 `LIT` 决定，与当前是否收到红石信号（`POWERED`）无关。
