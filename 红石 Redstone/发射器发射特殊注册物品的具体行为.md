以下是 `DispenserBehavior.registerDefaults()` 代码的**逐步解释**，按注册顺序分析每个行为的关键判断条件、操作和数据。

---

## 0. 代码整体结构

`registerDefaults()` 是静态方法，在游戏初始化时调用一次，用于为所有物品/方块在发射器中注册**特殊行为**。  
未注册的物品会使用默认的 `ItemDispenserBehavior`，即把物品作为掉落物丢出去。

- `DispenserBlock.registerBehavior(Item/Block, DispenserBehavior)`：注册行为。
- `DispenserBlock.registerProjectileBehavior(Item)`：快捷注册为投射物发射行为。
- 行为接口的核心方法是 `dispense(BlockPointer, ItemStack)`，返回发射后的物品栈；很多实现会重写 `dispenseSilently` 来做实际操作（不播放声音）。

---

## 1. 投射物类注册

```java
DispenserBlock.registerProjectileBehavior(Items.ARROW);
...
DispenserBlock.registerProjectileBehavior(Items.WIND_CHARGE);
```

**行为**：这些物品会被发射器以**投射物实体**高速发射。  
**内部实现**：`ProjectileDispenserBehavior` 会：

- 读取发射器朝向 `FACING`
- 在发射器前方生成对应投射物实体
- 给投射物设置初速度，方向为发射器朝向，速度约为 `0.5` 方块/刻
- 消耗 1 个物品

**注册物品**：箭、药水箭、光灵箭、鸡蛋、蓝鸡蛋、棕鸡蛋、雪球、经验瓶、喷溅药水、滞留药水、烟花火箭、火焰弹、风弹。

## 2. 刷怪蛋行为

```java
ItemDispenserBehavior itemDispenserBehavior = new ItemDispenserBehavior() {
    @Override
    public ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        Direction direction = pointer.state().get(DispenserBlock.FACING);
        EntityType<?> entityType = ((SpawnEggItem) stack.getItem()).getEntityType(stack);
        if (entityType == null) {
            return stack; // 无法解析实体类型，不消耗
        }
        try {
            entityType.spawnFromItemStack(
                pointer.world(), stack, null,
                pointer.pos().offset(direction),
                SpawnReason.DISPENSER,
                direction != Direction.UP,
                false
            );
        } catch (Exception exception) {
            LOGGER.error("Error while dispensing spawn egg from dispenser at {}", pointer.pos(), exception);
            return ItemStack.EMPTY;
        }
        stack.decrement(1);
        pointer.world().emitGameEvent(null, GameEvent.ENTITY_PLACE, pointer.pos());
        return stack;
    }
};
for (SpawnEggItem spawnEggItem : SpawnEggItem.getAll()) {
    DispenserBlock.registerBehavior(spawnEggItem, itemDispenserBehavior);
}
```

**关键判断**：

- `entityType == null`：如果刷怪蛋无法解析出实体类型，直接返回原物品，不消耗。
- 否则调用 `spawnFromItemStack` 生成实体。

**具体数据**：

- 生成位置：`pointer.pos().offset(direction)`，即发射器前方 1 格。
- 生成原因：`SpawnReason.DISPENSER`
- 参数 `direction != Direction.UP`：表示生成实体时是否根据方向设置朝向，非向上时为 `true`。
- 成功后：消耗 1 个刷怪蛋，发送 `ENTITY_PLACE` 游戏事件。

## 3. 盔甲架行为

```java
DispenserBlock.registerBehavior(Items.ARMOR_STAND, new ItemDispenserBehavior() {
    @Override
    public ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        Direction direction = pointer.state().get(DispenserBlock.FACING);
        BlockPos blockPos = pointer.pos().offset(direction);
        ServerWorld serverWorld = pointer.world();
        Consumer<ArmorStandEntity> consumer = EntityType.copier(
            armorStand -> armorStand.setYaw(direction.getPositiveHorizontalDegrees()),
            serverWorld, stack, null

        ArmorStandEntity armorStandEntity = EntityType.ARMOR_STAND.spawn(
            serverWorld, consumer, blockPos, SpawnReason.DISPENSER, false, false
        );
        if (armorStandEntity != null) {
            stack.decrement(1);
        }
        return stack;
    }
});
```

**关键判断**：

- `armorStandEntity != null`：只有成功生成实体才消耗物品。

**具体数据**：

- 生成位置：发射器前方 1 格。
- 盔甲架朝向：`direction.getPositiveHorizontalDegrees()`（南=0°，西=90°，北=180°，东=270°）。
- 成功后消耗 1 个盔甲架。

## 4. 箱子装备给驴/骡

```java
DispenserBlock.registerBehavior(Items.CHEST, new FallibleItemDispenserBehavior() {
    @Override
    public ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        BlockPos blockPos = pointer.pos().offset(pointer.state().get(DispenserBlock.FACING));

        for (AbstractDonkeyEntity abstractDonkeyEntity : pointer.world()
            .getEntitiesByClass(AbstractDonkeyEntity.class, new Box(blockPos),
                donkey -> donkey.isAlive() && !donkey.hasChest())) {
            if (abstractDonkeyEntity.isTame()) {
                StackReference stackReference = abstractDonkeyEntity.getStackReference(499);
                if (stackReference != null && stackReference.set(stack)) {
                    stack.decrement(1);
                    this.setSuccess(true);
                    return stack;
                }
            }
        }
        return super.dispenseSilently(pointer, stack);
    }
});
```

**关键判断**：

- 在发射器前方 1 格范围内查找 `AbstractDonkeyEntity`（驴/骡）。
- 过滤条件：`donkey.isAlive() && !donkey.hasChest()`：活着且未装备箱子。
- 额外判断：`donkey.isTame()`：必须已驯服。
- `getStackReference(499)`：获取驴/骡的箱子槽位引用。
- `stackReference.set(stack)`：尝试把箱子放入该槽位。

**具体数据**：

- 搜索范围：`new Box(blockPos)`，即前方 1 格的 1×1×1 方块区域。
- 槽位索引：`499`（马匹箱子槽位的稳定引用 ID）。
- 成功：消耗 1 个箱子，`setSuccess(true)`。
- 失败：调用 `super.dispenseSilently`，即默认丢出箱子。

## 6. 满桶放置液体/鱼

```java
DispenserBehavior dispenserBehavior = new ItemDispenserBehavior() {
    private final ItemDispenserBehavior fallback = new ItemDispenserBehavior();

    @Override
    public ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        FluidModificationItem fluidModificationItem = (FluidModificationItem) stack.getItem();
        BlockPos blockPos = pointer.pos().offset(pointer.state().get(DispenserBlock.FACING));
        World world = pointer.world();
        if (fluidModificationItem.placeFluid(null, world, blockPos, null)) {
            fluidModificationItem.onEmptied(null, world, stack, blockPos);
            return this.decrementStackWithRemainder(pointer, stack, new ItemStack(Items.BUCKET));
        } else {
            return this.fallback.dispense(pointer, stack);
        }
    }
};
DispenserBlock.registerBehavior(Items.LAVA_BUCKET, dispenserBehavior);
DispenserBlock.registerBehavior(Items.WATER_BUCKET, dispenserBehavior);
...
DispenserBlock.registerBehavior(Items.TADPOLE_BUCKET, dispenserBehavior);
```

**关键判断**：

- `fluidModificationItem.placeFluid(null, world, blockPos, null)`：尝试在前方方块放置液体或鱼。
  - 返回 `true`：放置成功。
  - 返回 `false`：放置失败，走默认丢出。

**具体数据**：

- 成功：消耗 1 个满桶，返还 1 个空桶。
- 失败：物品按默认行为丢出，不返还空桶。

## 7. 空桶装液体/鱼

```java
DispenserBlock.registerBehavior(Items.BUCKET, new ItemDispenserBehavior() {
    @Override
    public ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        WorldAccess worldAccess = pointer.world();
        BlockPos blockPos = pointer.pos().offset(pointer.state().get(DispenserBlock.FACING));
        BlockState blockState = worldAccess.getBlockState(blockPos);
        if (blockState.getBlock() instanceof FluidDrainable fluidDrainable) {
            ItemStack itemStack = fluidDrainable.tryDrainFluid(null, worldAccess, blockPos, blockState);
            if (itemStack.isEmpty()) {
                return super.dispenseSilently(pointer, stack);
            }
            worldAccess.emitGameEvent(null, GameEvent.FLUID_PICKUP, blockPos);
            Item item = itemStack.getItem();
            return this.decrementStackWithRemainder(pointer, stack, new ItemStack(item));
        } else {
            return super.dispenseSilently(pointer, stack);
        }
    }
});
```

**关键判断**：

- 前方方块是否实现 `FluidDrainable`。
- `tryDrainFluid` 返回的 `ItemStack` 是否为空：
  - 非空：装取成功。
  - 空：装取失败。

**具体数据**：

- 成功：消耗 1 个空桶，返还对应的满桶（水桶、熔岩桶、鱼桶等）。
- 失败：走默认丢出，不消耗。

## 8. 打火石

```java
DispenserBlock.registerBehavior(Items.FLINT_AND_STEEL, new FallibleItemDispenserBehavior() {
    @Override
    protected ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        ServerWorld serverWorld = pointer.world();
        this.setSuccess(true);
        Direction direction = pointer.state().get(DispenserBlock.FACING);
        BlockPos blockPos = pointer.pos().offset(direction);
        BlockState blockState = serverWorld.getBlockState(blockPos);
        if (AbstractFireBlock.canPlaceAt(serverWorld, blockPos, direction)) {
            serverWorld.setBlockState(blockPos, AbstractFireBlock.getState(serverWorld, blockPos));
            serverWorld.emitGameEvent(null, GameEvent.BLOCK_PLACE, blockPos);
        } else if (CampfireBlock.canBeLit(blockState) || CandleBlock.canBeLit(blockState) || CandleCakeBlock.canBeLit(blockState)) {
            serverWorld.setBlockState(blockPos, blockState.with(Properties.LIT, true));
            serverWorld.emitGameEvent(null, GameEvent.BLOCK_CHANGE, blockPos);
        } else if (blockState.getBlock() instanceof TntBlock) {
            if (TntBlock.primeTnt(serverWorld, blockPos)) {
                serverWorld.removeBlock(blockPos, false);
            } else {
                this.setSuccess(false);
            }
        } else {
            this.setSuccess(false);
        }

        if (this.isSuccess()) {
            stack.damage(1, serverWorld, null, item -> {});
        }
        return stack;
    }
});
```

**判断顺序与条件**：

1. `AbstractFireBlock.canPlaceAt(...)`：前方能否点燃火焰。  
   成功 → 放置火方块。
2. `CampfireBlock.canBeLit` / `CandleBlock.canBeLit` / `CandleCakeBlock.canBeLit`：前方是否是未点燃的营火/蜡烛/蛋糕蜡烛。  
   成功 → 设置 `Properties.LIT = true`。
3. 前方是否为 `TntBlock`：  
   - `TntBlock.primeTnt(...)` 返回 `true`：成功点燃并移除 TNT 方块。  
   - 返回 `false`：失败。
4. 以上都不满足 → 失败。

**具体数据**：

- 成功：消耗 1 点打火石耐久（`stack.damage(1, ...)`）。
- 失败：不消耗耐久，`setSuccess(false)`。

```java
DispenserBlock.registerBehavior(Items.BONE_MEAL, new FallibleItemDispenserBehavior() {
```

## 10. TNT

```java
DispenserBlock.registerBehavior(Blocks.TNT, new FallibleItemDispenserBehavior() {
    @Override
    protected ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        ServerWorld serverWorld = pointer.world();
        if (!serverWorld.getGameRules().getValue(GameRules.TNT_EXPLODES)) {
            this.setSuccess(false);
            return stack;
        } else {
            BlockPos blockPos = pointer.pos().offset(pointer.state().get(DispenserBlock.FACING));
            TntEntity tntEntity = new TntEntity(
                serverWorld,
                blockPos.getX() + 0.5,
                blockPos.getY(),
                blockPos.getZ() + 0.5,
                null
            );
            serverWorld.spawnEntity(tntEntity);
            serverWorld.playSound(
                null, tntEntity.getX(), tntEntity.getY(), tntEntity.getZ(),
                SoundEvents.ENTITY_TNT_PRIMED, SoundCategory.BLOCKS, 1.0F, 1.0F
            );
            serverWorld.emitGameEvent(null, GameEvent.ENTITY_PLACE, blockPos);
            stack.decrement(1);
            this.setSuccess(true);
            return stack;
        }
    }
});
```

**关键判断**：

- 游戏规则 `GameRules.TNT_EXPLODES` 是否允许 TNT 爆炸。  
  如果为 `false`：失败，不消耗物品，不生成 TNT。

**具体数据**：

- 生成位置：前方 1 格中心点，`x + 0.5, y, z + 0.5`。
- 生成实体：点燃的 `TntEntity`，引信时间默认约 80 gt（4 秒）。
- 成功消耗 1 个 TNT。

## 11. 凋灵骷髅头颅

```java
DispenserBlock.registerBehavior(Items.WITHER_SKELETON_SKULL, new FallibleItemDispenserBehavior() {
    @Override
    protected ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        World world = pointer.world();
        Direction direction = pointer.state().get(DispenserBlock.FACING);
        BlockPos blockPos = pointer.pos().offset(direction);
        if (world.isAir(blockPos) && WitherSkullBlock.canDispense(world, blockPos, stack)) {
            world.setBlockState(
                blockPos,
                Blocks.WITHER_SKELETON_SKULL.getDefaultState()
                    .with(SkullBlock.ROTATION, RotationPropertyHelper.fromDirection(direction)),
                Block.NOTIFY_ALL
            );
            world.emitGameEvent(null, GameEvent.BLOCK_PLACE, blockPos);
            BlockEntity blockEntity = world.getBlockEntity(blockPos);
            if (blockEntity instanceof SkullBlockEntity) {
                WitherSkullBlock.onPlaced(world, blockPos, (SkullBlockEntity) blockEntity);
            }
            stack.decrement(1);
            this.setSuccess(true);
        } else {
            this.setSuccess(EquippableDispenserBehavior.dispense(pointer, stack));
        }
        return stack;
    }
});
```

**关键判断**：

- `world.isAir(blockPos)`：前方必须是空气。
- `WitherSkullBlock.canDispense(world, blockPos, stack)`：检查头颅能否放置（例如周围不能有另一个同类头）。
- 不满足 → 尝试 `EquippableDispenserBehavior.dispense`，把头颅装备到附近生物头上。

**具体数据**：

- 放置时 `ROTATION` 由 `RotationPropertyHelper.fromDirection(direction)` 计算，方向与发射器一致。
- 成功消耗 1 个头颅。

## 14. 玻璃瓶装蜂蜜/水

```java
DispenserBlock.registerBehavior(Items.GLASS_BOTTLE.asItem(), new FallibleItemDispenserBehavior() {
    private ItemStack pickUpFluid(BlockPointer pointer, ItemStack inputStack, ItemStack outputStack) {
        pointer.world().emitGameEvent(null, GameEvent.FLUID_PICKUP, pointer.pos());
        return this.decrementStackWithRemainder(pointer, inputStack, outputStack);
    }

    @Override
    public ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        this.setSuccess(false);
        ServerWorld serverWorld = pointer.world();
        BlockPos blockPos = pointer.pos().offset(pointer.state().get(DispenserBlock.FACING));
        BlockState blockState = serverWorld.getBlockState(blockPos);
        if (blockState.isIn(BlockTags.BEEHIVES, state -> state.contains(BeehiveBlock.HONEY_LEVEL) && state.getBlock() instanceof BeehiveBlock)
            && blockState.get(BeehiveBlock.HONEY_LEVEL) >= 5) {
            ((BeehiveBlock) blockState.getBlock()).takeHoney(serverWorld, blockState, blockPos, null, BeehiveBlockEntity.BeeState.BEE_RELEASED);
            this.setSuccess(true);
            return this.pickUpFluid(pointer, stack, new ItemStack(Items.HONEY_BOTTLE));
        } else if (serverWorld.getFluidState(blockPos).isIn(FluidTags.WATER)) {
            this.setSuccess(true);
            return this.pickUpFluid(pointer, stack, PotionContentsComponent.createStack(Items.POTION, Potions.WATER));
        } else {
            return super.dispenseSilently(pointer, stack);
        }
    }
});
```

**判断条件与数据**：

- 蜂巢分支：  
  - `blockState.isIn(BlockTags.BEEHIVES, ...)`：是蜂巢/蜂箱。  
  - `HONEY_LEVEL >= 5`：蜜满。  
  成功：消耗 1 个玻璃瓶，返还 1 个蜂蜜瓶。

- 水分支：  
  - `fluidState.isIn(FluidTags.WATER)`：前方是水。  
  成功：消耗 1 个玻璃瓶，返还 1 个水瓶。

- 其他：走默认丢出，`setSuccess(false)`。

```java
        BlockPos blockPos = pointer.pos().offset(pointer.state().get(DispenserBlock.FACING));
        List<ArmadilloEntity> list = serverWorld.getEntitiesByClass(
            ArmadilloEntity.class, new Box(blockPos), EntityPredicates.EXCEPT_SPECTATOR
        );
        if (list.isEmpty()) {
            this.setSuccess(false);
            return stack;
        }

        for (ArmadilloEntity armadilloEntity : list) {
            if (armadilloEntity.brushScute(null, stack)) {
                stack.damage(16, serverWorld, null, item -> {});
                return stack;
            }
        }

        this.setSuccess(false);
        return stack;
    }
});
```

**关键判断**：

- 前方 1 格范围内是否存在 `ArmadilloEntity`（犰狳）。
- `brushScute` 返回 `true`：成功刷下鳞甲。

**具体数据**：

- 搜索范围：`new Box(blockPos)`（前方 1 格方块边界）。
- 成功后刷子消耗 16 点耐久。
- 失败：`setSuccess(false)`，不消耗。

## 19. 水瓶转化为泥

```java
DispenserBlock.registerBehavior(Items.POTION, new ItemDispenserBehavior() {

    @Override
    public ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        PotionContentsComponent potionContentsComponent =
            stack.getOrDefault(DataComponentTypes.POTION_CONTENTS, PotionContentsComponent.DEFAULT);
        if (!potionContentsComponent.matches(Potions.WATER)) {

        }

        ServerWorld serverWorld = pointer.world();
```

## 21. 默认行为（未注册物品）

```java
public interface DispenserBehavior {
    DispenserBehavior NOOP = (pointer, stack) -> stack;
    ItemStack dispense(BlockPointer pointer, ItemStack stack);
}
```

- 未注册特殊行为的物品使用 `ItemDispenserBehavior` 默认实例。
- 默认行为：将物品作为掉落物实体从发射器前方弹出。
  - 初速度较低，方向沿发射器朝向，带轻微随机偏移。
  - 不消耗耐久、不执行特殊交互。


    ## 2. 默认发射行为：`dispenseSilently`

    ```java
    protected ItemStack dispenseSilently(BlockPointer pointer, ItemStack stack) {
        Direction direction = pointer.state().get(DispenserBlock.FACING);
        Position position = DispenserBlock.getOutputLocation(pointer);
        ItemStack itemStack = stack.split(1);
        spawnItem(pointer.world(), itemStack, 6, direction, position);
        return stack;
    }
    ```

    - `Direction direction`：发射器朝向。
    - `Position position`：`DispenserBlock.getOutputLocation(pointer)`，通常是发射器口前方约 0.5 格处的精确坐标。
    - `stack.split(1)`：从传入的物品栈中**分离出 1 个物品**，作为要发射的物品；原栈数量减 1 并返回。
    - 调用 `spawnItem` 生成掉落物实体，速度参数固定为 `6`。

    ---

    ## 3. 核心速度数据：`spawnItem`

    ```java
    public static void spawnItem(World world, ItemStack stack, int speed, Direction side, Position pos) {
        double d = pos.getX();
        double e = pos.getY();
        double f = pos.getZ();
        if (side.getAxis() == Direction.Axis.Y) {
            e -= 0.125;
        } else {
            e -= 0.15625;
        }

        ItemEntity itemEntity = new ItemEntity(world, d, e, f, stack);
        double g = world.random.nextDouble() * 0.1 + 0.2;
        itemEntity.setVelocity(
            world.random.nextTriangular(side.getOffsetX() * g, 0.0172275 * speed),
            world.random.nextTriangular(0.2, 0.0172275 * speed),
            world.random.nextTriangular(side.getOffsetZ() * g, 0.0172275 * speed)
        );
        world.spawnEntity(itemEntity);
    }
    ```

    1. **水平速度系数 `g`**  
    ```java
    double g = world.random.nextDouble() * 0.1 + 0.2;
    ```
    `g` 的取值范围是 **[0.2, 0.3)**，每次发射随机。  
    它用于计算水平速度的平均值。

    2. **水平速度（X / Z 轴）**  
    ```java
    world.random.nextTriangular(side.getOffsetX() * g, 0.0172275 * speed)
    ```
    - 均值：`side.getOffsetX() * g` 或 `side.getOffsetZ() * g`  
        如果发射器朝向 X 轴，则 X 速度均值为 `±g`，Z 速度均值为 `0`；反之亦然。  
        所以水平方向**主要沿发射器朝向**，平均大小在 `0.2 ~ 0.3` 方块/刻。
    - 最大随机偏差：`0.0172275 * speed`  
        `speed = 6`，所以偏差为 `0.0172275 * 6 = 0.103365`。
    - `nextTriangular(mean, maxDeviation)` 生成一个**三角分布**随机数，范围大致是 `mean ± maxDeviation`，因此水平速度会在均值附近波动，不会偏离太远。

    3. **垂直速度（Y 轴）**  
    ```java
    world.random.nextTriangular(0.2, 0.0172275 * speed)
    ```
    - 均值：`0.2` 方块/刻。
    - 最大偏差：`0.103365`。
    - 所以 Y 速度大致在 `0.0966 ~ 0.3034` 之间，物品会稍微向上弹出并下落。

    4. **总速度特性**  
    - 默认发射的物品不是高速“射出”，而是**缓慢弹出**。  
    - 水平速度约 `0.2 ~ 0.3` 方块/刻，垂直速度约 `0.2` 方块/刻。  
    - 换算成每秒（20 刻/秒）约 `4 ~ 6` 方块/秒。  
    - 加上随机三角分布，物品轨迹会有轻微散布。

    ### 坐标微调

    ```java
    if (side.getAxis() == Direction.Axis.Y) {
        e -= 0.125;
    } else {
        e -= 0.15625;
    }
    ```

    - 如果发射器朝上或朝下（Y 轴），物品生成位置 Y 坐标下移 `0.125`。
    - 如果朝水平方向，Y 坐标下移 `0.15625`。
    - 这样物品会从发射器口中心偏下的位置生成，更符合视觉。

    ## 5. `decrementStackWithRemainder`

    ```java
    protected ItemStack decrementStackWithRemainder(BlockPointer pointer, ItemStack stack, ItemStack remainder) {
        stack.decrement(1);
        if (stack.isEmpty()) {
            return remainder;
        }
        this.addStackOrSpawn(pointer, remainder);
        return stack;
    }
    ```

    这个方法在注册代码的**桶类、水瓶、玻璃瓶**等行为中被大量使用，例如：

    - 满桶行为：`return this.decrementStackWithRemainder(pointer, stack, new ItemStack(Items.BUCKET));`
    - 空桶行为：`return this.decrementStackWithRemainder(pointer, stack, new ItemStack(item));`
    - 玻璃瓶装水：`return this.pickUpFluid(pointer, stack, new ItemStack(Items.HONEY_BOTTLE));`

    ### 逻辑说明

    - 先消耗掉原物品栈中的 1 个物品（`stack.decrement(1)`）。
    - 如果栈**空了**（例如只有 1 个满桶），直接返回 `remainder`（比如空桶），这个 `remainder` 会成为发射器内新的物品栈。
    - 如果栈**还有剩余**（例如放了 5 个满桶，发射 1 个后还剩 4 个），则调用 `addStackOrSpawn`：
    - 先尝试把 `remainder`（空桶）放入发射器内部的其他空槽位；
    - 如果放不下，则把空桶作为掉落物从发射器前方发射出去，并同步发送发射事件。

    这样设计是为了支持发射器内堆叠物品时，消耗一个满桶后产生的空桶能合理处理。

    ## 6. 注册代码与默认发射的关系

    在 `registerDefaults()` 中，大量特殊行为在**条件不满足时**会回退到默认发射：

    ```java
    return super.dispenseSilently(pointer, stack);
    // 或
    return this.fallback.dispense(pointer, stack);
    // 或
    return this.fallbackBehavior.dispense(pointer, stack);
    ```

    这些回退最终都会调用 `ItemDispenserBehavior` 的默认 `dispenseSilently`，即**使用速度参数 `6` 将物品作为掉落物弹出**。

    例如：

    - 箱子不能装备给驴/骡时 → 默认丢出箱子。
    - 满桶无法放置液体/鱼时 → 默认丢出满桶。
    - 空桶无法装取液体时 → 默认丢出空桶。
    - 打火石无法点火/点燃时 → 默认丢出打火石，但不消耗耐久。
    - 玻璃瓶不能装蜂蜜/水时 → 默认丢出玻璃瓶。
    - 荧石前方不是重生锚或已满充能时 → 默认丢出荧石。

    也就是说，**所有未注册特殊行为的物品**，以及**特殊行为失败后的回退**，都使用上面分析的同一套默认发射物理参数。
