# 拉杆 Lever

## 一、方块状态

拉杆有 3 个方块状态：

| 属性      | 类型                | 含义                                                                         | 默认值            |
| --------- | ------------------- | ---------------------------------------------------------------------------- | ----------------- |
| `FACE`    | `AttachFace`        | 拉杆附着在方块的哪个面：`FLOOR`（地面）、`CEILING`（天花板）、`WALL`（侧面） | `AttachFace.WALL` |
| `FACING`  | `Direction`（水平） | 拉杆的朝向，与 `FACE` 共同决定拉杆头部的方向                                 | `Direction.NORTH` |
| `POWERED` | `BooleanProperty`   | 拉杆是否激活、输出红石信号                                                   | `false`           |

- `FACE` 决定拉杆附着在哪个面，`FACING` 决定水平朝向，两者组合通过 `getConnectedDirection(state)` 计算出拉杆的输出方向（即拉杆头部指向的方向）。
- 放置时，根据玩家点击的面和视角方向自动确定 `FACE` 和 `FACING`。
