# 音符盒 Note Block

---

## 一、方块状态

音符盒有 3 个方块状态：

| 属性         | 类型                                | 含义                                    | 默认值  |
| ------------ | ----------------------------------- | --------------------------------------- | ------- |
| `INSTRUMENT` | `EnumProperty<NoteBlockInstrument>` | 当前乐器                                | `HARP`  |
| `POWERED`    | `BooleanProperty`                   | 是否被红石信号激活                      | `false` |
| `NOTE`       | `IntegerProperty`                   | 音高编号，范围为 `0~24`，共两个八度音域 | `0`     |

- `NOTE` 为 `0` 时音高为低八度，`12` 为基准音高，`24` 为高八度。
- 使用空手右键音符盒时，`NOTE` 会循环递增。

---

## 二、乐器判定

音符盒的乐器由上下方方块共同决定。

### 放置时

`getStateForPlacement` 会调用 `setInstrument`，根据放置位置的上下方块设置初始乐器。

### 邻居更新时

在 `updateShape` 中：

- 只有上下方向（`Direction.Axis.Y`）的邻居变化，才会重新判定乐器。
- 水平方向邻居变化不会改变音符盒的乐器。

### `setInstrument` 判定顺序

1. 先检查音符盒**上方**方块的 `instrument()`：
   - 如果上方乐器满足 `worksAboveNoteBlock() == true`，则直接采用上方乐器。

2. 如果上方乐器不满足，再检查**下方**方块的 `instrument()`：
   - 如果下方乐器满足 `worksAboveNoteBlock() == false`，则采用下方乐器
   - 如果下方乐器也满足 `worksAboveNoteBlock() == true`，说明它是本应放在上方生效的特殊乐器，此时会忽略它，并将乐器回退为 `HARP`。

因此：

- 普通乐器由**下方方块**决定。
- 生物头颅等特殊乐器必须放在音符盒**上方**才能生效。

---

## 三、演奏触发

### 1. 红石信号触发

**音符盒收到邻居更新（NC更新）后**

- 检测是否收到红石信号。
- 当红石信号状态与当前 `POWERED` 状态不一致时：
  - 如果从无信号变为有信号，即 `false -> true`：
    1. 使用当前旧状态调用 `playNote(null, state, level, pos)` 演奏一次。
    2. 将方块状态设置为 `POWERED = true`。
  - 如果从有信号变为无信号，即 `true -> false`：
    - 仅将 `POWERED` 设置为 `false`，不会演奏。

也就是说，音符盒在红石信号上升沿演奏一次，信号持续期间不会重复演奏；必须等待信号消失后再次触发，才会再次演奏。

有关`playNote`，见下文 **四、发声条件**

### 2. 玩家右键

空手右键音符盒时：

- 服务端将 `NOTE` 循环加 1。
- 使用新状态调用 `playNote` 播放对应音高。
- 给予玩家 `Stats.TUNE_NOTEBLOCK` 统计。
- 客户端也返回成功。

该操作会改变音符盒音高并立即演奏一次。

### 3. 玩家左键攻击

左键攻击音符盒时：

- 服务端使用当前状态调用 `playNote` 演奏。
- 给予玩家 `Stats.PLAY_NOTEBLOCK` 统计。
- 不会改变 `NOTE` 音高。

### 4. 物品使用

在 `useItemOn` 中：

- 如果玩家手持物品属于 `ItemTags.NOTE_BLOCK_TOP_INSTRUMENTS`，且点击的是音符盒**顶面**，则返回 `InteractionResult.PASS`。
- 这样可以让该头颅直接放置到音符盒上方，不需要按住shift键

---

## 四、发声条件
`playNote` 不是直接播放声音，而是先判断条件，再通过方块事件发送给客户端播放。

只有满足以下任一条件时，才会实际发声：

1. 当前乐器满足 `worksAboveNoteBlock() == true`；
2. 音符盒**上方方块是空气**。

否则不会发送方块事件，也不会播放声音。

满足条件后，`playNote` 会：

- 调用 `level.blockEvent(pos, this, 0, 0)` 添加方块事件 负责同步客户端播放声音显示粒子
   在下一个BE阶段执行
- 调用 `level.gameEvent(...)` 发送 `GameEvent.NOTE_BLOCK_PLAY` 添加一个游戏事件 负责幽匿感测体的声音检测

因此：

- 普通乐器音符盒上方被非空气方块遮挡时不会发声。
- 特殊上方乐器（例如生物头颅）即使上方不为空气，也能正常发声。

---

## 五、声音与粒子事件

`triggerEvent` 在客户端处理音符盒的声音和粒子效果。

### 音高计算

- 如果乐器 `isTunable()` 为 `true`：
  - 根据当前 `NOTE` 计算音高：
    \[
    pitch = 2^{(note - 12) / 12}
    \]
  - 同时在音符盒上方生成音符粒子：
    - 粒子类型：`ParticleTypes.NOTE`
    - 位置：`pos.getX() + 0.5`, `pos.getY() + 1.2`, `pos.getZ() + 0.5`
    - 粒子参数：`note / 24.0`

- 如果乐器的 `isTunable()` 为 `false`：
  - 音高固定为 `1.0F`。
  - 不生成音符粒子。

### 自定义声音播放

- 如果乐器 `hasCustomSound()` 为 `true`：
  - 从音符盒上方方块实体获取自定义声音 ID。
  - 只有上方方块实体是 `SkullBlockEntity` 且能提供声音 ID 时才会播放。
  - 否则返回 `false`，不播放声音。

- 如果乐器没有自定义声音：
  - 使用乐器默认的 `getSoundEvent()`。

声音播放参数：

- 音源位置：`pos.getX() + 0.5`, `pos.getY() + 0.5`, `pos.getZ() + 0.5`
- 声音类别：`SoundSource.RECORDS`
- 音量：`3.0F`
- 音高：由上方规则计算得出
- 随机种子：`level.getRandom().nextLong()`

## 二、生物头颅类（MOB_HEAD）

必须放置在音符盒**上方**才能生效，由对应生物头颅决定音色，共 6 种。生物头颅类乐器**不可调音**（`isTunable() == false`），音高固定为 `1.0F`，不生成音符粒子。发声时音符盒上方不需要是空气，因为头颅本身就是非空气方块。

| 枚举值            | 序列化名称        | 声音事件                             | 决定方块     |
| ----------------- | ----------------- | ------------------------------------ | ------------ |
| `ZOMBIE`          | `zombie`          | `NOTE_BLOCK_IMITATE_ZOMBIE`          | 僵尸头颅     |
| `SKELETON`        | `skeleton`        | `NOTE_BLOCK_IMITATE_SKELETON`        | 骷髅头颅     |
| `CREEPER`         | `creeper`         | `NOTE_BLOCK_IMITATE_CREEPER`         | 苦力怕头颅   |
| `DRAGON`          | `dragon`          | `NOTE_BLOCK_IMITATE_ENDER_DRAGON`    | 末影龙头     |
| `WITHER_SKELETON` | `wither_skeleton` | `NOTE_BLOCK_IMITATE_WITHER_SKELETON` | 凋灵骷髅头颅 |
| `PIGLIN`          | `piglin`          | `NOTE_BLOCK_IMITATE_PIGLIN`          | 猪灵头颅     |

---

## 三、自定义声音类（CUSTOM）

仅 1 种，需要上方方块实体提供自定义声音 ID。

| 枚举值        | 序列化名称    | 声音事件                  | 说明                                                                                          |
| ------------- | ------------- | ------------------------- | --------------------------------------------------------------------------------------------- |
| `CUSTOM_HEAD` | `custom_head` | `UI_BUTTON_CLICK`（占位） | 音符盒上方方块实体为 `SkullBlockEntity` 时，通过 `head.getNoteBlockSound()` 获取自定义声音 ID |

- `CUSTOM_HEAD` 的 `hasCustomSound()` 返回 `true`。
- 播放时会查找音符盒上方的 `SkullBlockEntity`：
  - 如果存在且能返回有效的自定义声音 ID，则播放该声音。
  - 如果不存在或返回 `null`，则**不播放任何声音**（`triggerEvent` 返回 `false`）。
- `CUSTOM_HEAD` 的 `isTunable()` 返回 `false`，音高固定为 `1.0F`，不生成音符粒子。
